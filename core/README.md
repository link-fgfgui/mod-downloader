# mod-downloader/core

Core Go packages for mod-downloader: configuration, metadata providers, Minecraft instance discovery, download orchestration, local mod parsing, and the browser-extension HTTP bridge.

> The legacy module path `github.com/link-fgfgui/mod-downloader-core` is
> deprecated; use `github.com/link-fgfgui/mod-downloader/core` instead.
